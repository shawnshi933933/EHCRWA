X 数据接口或网页截图服务失败，不能据此断言公开主页不可访问，也不能断言帖子无法读取。

**Why:** EHC DEX 的接口请求返回 402、截图服务未生成截图，但普通主页请求随后成功，页面本身带有头像地址和部分近期帖子的文本。此前“读不到”的结论超过了工具失败所能支持的范围。

**How to apply:** 对访问能力的结论应基于实际返回内容，分别说明哪个渠道成功或失败。拿到主页中的部分帖子，不等于完整历史抓取，也不等于已完成近期内容分析；界面提取图与来自账号的头像原文件也应明确区分。
