第一阶段交付局限于信息呈现，去掉交易撮合部分，只关注股票，不包含黄金白银。用户允许以 CoinMarketCap 的 RWA 页面为数据来源。

**Why:** 用户在客户看过初稿后明确提出整改，并强调“整个这是第一阶段，交付就局限在信息呈现上，越专业越好”。

**How to apply:** 不沿用早期聚合交易 DEX 的执行功能范围，不把钱包、交易计算或跨链执行作为本阶段交付。数据可视化要帮助理解底层股票、发行方和 CEX/DEX 市场的关系，而不是增加装饰。

用户要求左右排布的三栏综合关系图：左侧股票总体基本面、股票 RWA 市值、简介及财报链接；中间按发行方拆解市值与 Token 信息；点击发行方后右侧展示 CEX/DEX 流动性信息。并列二级页面按发行方展示其股票 RWA 及相关排名，两者是同一矩阵的不同视角。Landing 上的项目介绍保留。

**Why:** 这是用户指定的信息结构，也是希望相较 CMC 显得更专业的呈现重点。

**How to apply:** 后续页面设计与数据接入须共同满足两个视角和品牌介绍，不将需求缩减为普通代币排行榜、单个价格走势图或只做股票关系图而遗漏发行方专页。
